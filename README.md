# Alternate Energies

A responsive static website for Alternate Energies Limited. Open `index.html` directly, or run `python -m http.server 3000` in this directory and visit http://localhost:3000.

## Included

- Solar installation, maintenance, commercial rooftop partnerships and direct solar power supply.
- Coverage across East Africa, London and Norwich, as supplied by the client.
- Mobile navigation, service preselection and a validated enquiry form that creates a local downloadable text draft.
- Keyboard focus styles, labelled fields, skip navigation and reduced-motion support.

## Before launch

- Contact addresses: sales@alternateenergieslimited.com, info@alternateenergieslimited.com and purchase@alternateenergieslimited.com.
- Connect the form to a real enquiry endpoint and add the appropriate privacy information before collecting customer data. The current form prepares a mailto link to Sales and a downloadable draft. Visitors send the email themselves in their email app; the website does not submit or store enquiries.
- Confirm service availability and commercial terms with the company. Do not add unsupported project counts, performance guarantees or accreditations.
- VAT number supplied by the client has not been independently verified and is omitted from the website.
- Google Fonts load externally. Illustrative Unsplash photographs are bundled in assets/ and are not presented as company project photographs.
